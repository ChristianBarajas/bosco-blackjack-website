# Bosco Blackjack Website

Production website built for Bosco Blackjack, a private blackjack entertainment business serving Southern California.

## Live Website

https://bosco-blackjack.web.app

## Overview

Bosco Blackjack provides professional blackjack table rentals for private parties, corporate events, casino nights, birthdays, and special events.

This website was developed to provide:

* Business information and pricing
* Event photo and video gallery
* Customer booking request form
* Direct contact information
* Mobile-friendly user experience

Booking requests are stored in Firebase Firestore and can be reviewed by the business owner.

## Installation

Clone the repository:

```bash
git clone https://github.com/ChristianBarajas/bosco-blackjack-website.git
```

Navigate into the project:

```bash
cd bosco-blackjack-website
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

---

## Firebase Configuration

Create a Firebase project and configure the application using your Firebase credentials.

Required services:

* Firebase Firestore
* Firebase Hosting
